<div class="home-lead">
  Media Pipeline SDK is a TypeScript package for converting source video into
  an HLS package — producing a master playlist, variant playlists, and segment
  files — and optionally pushing that package to Cloudinary under a predictable
  folder layout or to Amazon S3 with signed playback links.
</div>

<section class="home-section">
  <h2 class="home-section-title">Built for the media pipeline</h2>
  <div class="capability-list">
    <div class="capability">
      <div class="capability-head">
        <span class="capability-accent"></span>
        <strong>Local HLS generation</strong>
      </div>
      <p>
        Convert `.mp4`, `.mov`, and `.mkv` inputs into a `master.m3u8` playlist
        with variant outputs stored under your configured local directory.
      </p>
      <a class="capability-link" href="/guides/local-processing/">Local Processing →</a>
    </div>
    <div class="capability">
      <div class="capability-head">
        <span class="capability-accent"></span>
        <strong>Cloudinary delivery</strong>
      </div>
      <p>
        Upload generated HLS playlists and segments to Cloudinary under
        `mediapipeline/{videoId}/` and return the master playlist URL.
      </p>
      <a class="capability-link" href="/guides/cloudinary-upload/">Cloudinary Uploads →</a>
    </div>
    <div class="capability">
      <div class="capability-head">
        <span class="capability-accent"></span>
        <strong>S3 delivery with signed playback</strong>
      </div>
      <p>
        Upload generated HLS outputs to S3, generate signed playlists and
        signed segment links, and return a time-limited playback URL.
      </p>
      <a class="capability-link" href="/guides/s3-upload/">S3 Uploads →</a>
    </div>
    <div class="capability">
      <div class="capability-head">
        <span class="capability-accent"></span>
        <strong>Built-in presets</strong>
      </div>
      <p>
        Use exported HLS bitrate profiles and resolution mappings instead of
        maintaining ffmpeg settings manually.
      </p>
      <a class="capability-link" href="/reference/presets/">View Presets →</a>
    </div>
  </div>
</section>

<details class="home-more">
  <summary>See the full API output shapes</summary>

  Local processing returns a structured result:

  ```ts
  {
    type: "video",
    variants: [
      {
        name: "hls",
        path: "output/<uuid>/master.m3u8",
      },
    ],
  }
  ```

  Cloudinary processing returns a single string:

  ```ts
  "https://res.cloudinary.com/<cloud-name>/raw/upload/.../mediapipeline/<uuid>/master.m3u8";
  ```

  S3 processing also returns a single string:

  ```ts
  "https://<bucket>.s3.<region>.amazonaws.com/<folder>/<uuid>/signed/master.m3u8?...";
  ```

</details>
